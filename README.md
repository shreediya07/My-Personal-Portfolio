Welcome to my personal portfolio website!

I am **Shreediya Kunwar**, a BIT student with a strong interest in **Web Design, UI/UX Design, and Front-End Development**. I enjoy creating simple, attractive, and user-friendly web interfaces and exploring different layouts, colors, typography, and visual elements.

## 👩‍💻 About the Project

This is my personal portfolio website created using **semantic HTML5**.

The website presents my:

- Personal introduction
- Web design interests
- Technical and design skills
- Academic and practice projects
- Contact information

The main goal of this project is to practice semantic HTML structure while presenting my interests and skills in a simple and organized way.
